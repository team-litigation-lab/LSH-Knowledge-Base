### Overview

This procedure explains how to assign and complete tasks properly, and how to write notes in specific areas. Tasks and notes keep cases worked efficiently.

### Notes

- **All notes go in the Activity section, in the matching bucket** (see the buckets procedure). Notes in the buckets are time and date stamped, and only the original author can change them.
- Notes can be copied and pasted into the matching tabs, such as Negotiations, an individual medical provider, Billable Expenses or an individual insurance company. These notes let everyone know when something has been done, so tasks are not duplicated.
- **There must be a note in the bucket any time a task is assigned.** When you write a note for a specific section (meds, insurance, billable expenses or negotiations), write the date, your note (you can copy and paste it from the activity section) and your initials.
- **The most recent note always goes at the top.**

**Format:** (date) (task information) (initials).
**Example:** *8/17/23 - Assigned a task to a team member to follow up on the liability dec page. (initials)*

**Example:** A task is assigned to a team member in the "Liability Insurance" bucket to follow up on the liability dec page. The person then goes to the insurance tab and notes that the task was assigned. This keeps the same task from being assigned to someone else, and because the task is assigned outside the bucket, the notes keep accurate information on when the task was assigned and when it was completed.

When the team member receives the dec page, they check off the task and write a note in the matching bucket.

### Tasks

- **Do not re-use tasks.** Re-using a task creates inaccurate task completion times.
- **Assign tasks outside of the buckets AND write a note in the bucket** saying that you assigned the task.
- **When a task is completed, check it off as completed** and enter a note that refers to the bucket for the detailed notes, if applicable.
  - *Example:* On a client call-back task, write "See client call bucket" when it is completed. The detailed notes of the conversation go in the client call bucket.
- **A task can be assigned in a bucket only once.** If a task was already assigned, whether complete or not, assign a new task outside the bucket and write a note in the bucket that a task was assigned. This avoids several people working on the same task.
  - *Example:* A team member needs to assign a task to follow up on the hospital records, but a previous task was assigned to someone else to follow up on the ortho records. She writes a note in the bucket saying she assigned a task to follow up on the hospital records. Once that person follows up, they check off the task and write a detailed note, "See Treatment / Recs and Bills bucket", where the detailed notes are.

### Assigning several tasks at once

When you assign a task for several things, such as filing a UM claim, a liability claim and a subrogation claim, **assign one task in each matching bucket** and attach any documents that help the team member complete it.

- *Example:* If a VA is to file the liability claim and the UM claim, assign one task in the liability bucket and another in the UM bucket, with the police report attached if it is available. This keeps track of all the tasks completed during the day.
- If a task is to request hospital records and bills, attach the **discharge documents**.
- If a task is to file the health insurance subrogation, include the **front and back of the health insurance card**.
